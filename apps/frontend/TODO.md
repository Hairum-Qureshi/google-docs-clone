### MVP
[ ] Being able to create a document 
[ ] Being able to view all created documents 
[ ] Being able to have all data on document autosave
[ ] Being able to write in the document with the necessary formatting 
[ ] Being able to invite other users to the document via email
[ ] Being able to see which user is who with on the document
[ ] Being able to remove a user from the document
[ ] Being able to see changes as they're happening
[ ] Being able to make documents public/private
    -> if a document is private, only the author of the document and any users they've invited should be able to view it
    -> if the document is public, other users can view the document, but will be on read-only mode so no edits can occur
[ ] Middleware - don't allow unauthenticated users from accessing authenticated routes
